# أمين بالراشد — منصة تجارة الجملة

نسخة تجريبية Mobile-first لمتجر جملة.

## ما الموجود؟
- كتالوج منتجات بالجملة مع صور وأسعار ووحدة بيع وحد أدنى.
- بحث وتصنيفات.
- سلة طلبية.
- إنشاء طلبية باسم المحل ورقم الهاتف ووقت الاستلام.
- لوحة تحكم للطلبات وتغيير حالتها.
- منتجات تجريبية جاهزة.
- تصميم متجاوب للهاتف والكمبيوتر.

## مهم
هذه النسخة تعمل كـ Demo باستخدام localStorage، لذلك لوحة التحكم والطلبات في نفس المتصفح فقط.
لتحويلها إلى "تحكم حقيقي" بين الزبائن وصاحب المتجر نربطها بقاعدة بيانات/Backend مثل Supabase، مع تسجيل دخول للمشرف وصلاحيات وإشعارات.

## التشغيل
ارفع المجلد كما هو إلى Vercel أو Netlify، أو شغله عبر أي static server.
